# Getting Started

## Installation
1. Ensure you have the executable file (`moroccan_docs`) or build it from source.
2. No installation is required; the application is a standalone portable executable.

## First Run
When you launch the application for the first time, you will be greeted by the **Onboarding Wizard**.

### Onboarding Steps
1. **Welcome**: Introduction to the system.
2. **Location**: Enter your **Commune** and **Arrondissement** names. These will appear on all generated documents.
3. **Identity**: Enter your **Name** and **Grade** (Inspector Information).
4. **Database**: Confirm the location of the `police_administrative.xlsx` database file. It defaults to a `store` folder next to the executable.

After completing the wizard, click **Finish**.

## Logging In
- **Default Password**: `admin`
- Enter the password and click **Enter** to access the main dashboard.

## Dashboard Overview
The dashboard provides a quick summary of:
- Total Commerces Registered
- Total Inspections Performed
- Documents Generated
- Fines Issued & Collected
- Pending Actions & Overdue Tasks

## Document Storage
Generated documents are saved in the `docs/` folder located in the same directory as the application. You can open this folder directly from the **Documents Registry** view.
